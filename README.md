# Power BI Dashboard Projects

This repository contains Power BI dashboard and reporting practice files focused on business analysis, KPI tracking, sales reporting, and dataset exploration. The work supports my Data Analyst profile by showing dashboard-building practice with structured datasets, Excel files, Power BI reports, and DAX-based business metrics.

## Main Focus

The primary analytics direction of this repository is a **Sales Analysis Dashboard** built around business reporting use cases such as:

- Total sales and average sales tracking
- Month-over-month performance review
- Product, region, and customer-level sales analysis
- KPI cards, slicers, and trend visuals
- Data cleaning and preparation before dashboard creation

## Tools Used

- Power BI
- DAX
- Microsoft Excel
- Structured business datasets
- Dashboard design and reporting concepts

## What This Repository Demonstrates

- Converting structured datasets into dashboard-ready views
- Building visual reports for sales and business performance
- Using KPI cards, slicers, charts, and trend visuals for reporting
- Practicing DAX measures and Power BI report design
- Presenting business data in a clean, reviewable format

## Suggested Review Order

1. Open the `.pbix` files in Power BI Desktop.
2. Review the dashboard pages, filters, and KPI cards.
3. Check the dataset fields and relationships where available.
4. Review calculated measures and visuals used in the report.
